# Release GitHub Pages — v1.0

Esta versão prepara a checklist para publicação direta no GitHub Pages.

## Conteúdo

- `index.html` — app completo em arquivo único.
- `README.md` — instruções de publicação e créditos.
- `LICENSE` — licença MIT do código/textos autorais.
- `.nojekyll` — evita processamento pelo Jekyll no GitHub Pages.
- `.gitignore` — ignora arquivos comuns de sistema/editor.
